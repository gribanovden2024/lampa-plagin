# lampa-plagin

Объединённый плагин для приложения [Лампа](https://cub.red/lampa): два плагина в одном файле,
одна ссылка для установки.

## Установка

```
https://gribanovden2024.github.io/lampa-plagin/lampa-plagin.js
```

Лампа → Настройки → Расширения → «Добавить плагин» → вставить адрес.

> Если раньше был добавлен отдельный плагин Кинопоиска
> (`.../lampa/kinopoisk.js`) — удалите его, иначе компонент зарегистрируется дважды.

## Что внутри

### 1. Кинопоиск — «Буду смотреть»

Список из папки «Буду смотреть» на Кинопоиске прямо в Лампе.

Отличия от оригинального плагина [and7ey/lampa](https://github.com/and7ey/lampa):

- OAuth-токен **не** отправляется в чужой Google Apps Script: запросы идут через
  собственный Cloudflare Worker, токен передаётся в теле POST и не логируется;
- адрес прокси и ключ задаются в настройках Лампы (Настройки → Кинопоиск → «Свой прокси»);
- грузится весь список, а не первые 50 (страницы по 20, потолок 1000);
- исправлены падение настроек, `undefined` в пустых полях и невнятные ошибки.

Код Worker и инструкция: [`proxy/cloudflare-worker/`](proxy/cloudflare-worker/README.md).

### 2. Strawberry / sisi (si.skaz.tv)

Контент-плагин с сервера `si.skaz.tv`, скопирован без изменений.

> ⚠️ Плагин работает по **HTTP** (у `si.skaz.tv` нет TLS) и содержит канал удалённого
> управления: подключается по WebSocket к адресу из ответа сервера и выполняет команды
> через `eval`. На сервер уходят `account_email` из Лампы, `unic_id`, `box_mac`,
> `profile_id`. Любой в сети между телевизором и сервером может подменить ответ.

Реклама перед видео (`bid.ctv.house`) отключена на уровне Private DNS телевизора,
к плагинам она отношения не имеет.

## Сборка

Исходники лежат отдельно, рабочий файл собирается из них:

```
src/kinopoisk.js
src/sisi.js
      ↓  node build.mjs
lampa-plagin.js
```

Правьте `src/`, затем `node build.mjs`, затем коммит.

## Состав репозитория

```
lampa-plagin.js              готовый плагин (то, что ставится в Лампу)
src/kinopoisk.js             исходник Кинопоиска
src/sisi.js                  исходник sisi
build.mjs                    сборка
proxy/cloudflare-worker/     CORS-прокси для Кинопоиска (Cloudflare Worker)
```
