# lampa-plagin

Плагины для приложения [Лампа](https://cub.red/lampa). В Лампу добавляется **одна ссылка** —
установщик, который сам подгружает отдельные плагины.

## Установка

```
https://gribanovden2024.github.io/lampa-plagin/lampa-plagin.js
```

Лампа → Настройки → Расширения → «Добавить плагин» → вставить адрес.

> Если раньше был добавлен отдельный плагин Кинопоиска
> (`.../lampa/kinopoisk.js`) — удалите его, иначе компонент зарегистрируется дважды.

## Настройки

Все плагины добавляют в настройки Лампы собственные пункты — по одному на плагин:

```
Настройки
├── Кинопоиск
│   ├── Свой прокси (адрес, ключ)
│   ├── Аккаунт (вход/выход, почта)
│   └── Список «Буду смотреть» (избранное, очистка кэша)
├── Телевидение
│   ├── Включить (по умолчанию «Да»)
│   ├── Название раздела
│   ├── Встроенный плейлист (ссылка не настраивается)
│   ├── Программа (XMLTV)
│   └── Прокси для M3U/XMLTV
├── ТВ онлайн
│   ├── Включить (по умолчанию «Да»)
│   ├── Потоки: совместимые / официальные HD
│   └── Часовой пояс каналов: авто / МСК+0 / +2 / +4 / +7
└── Strawberry 18+
    └── Включить — по умолчанию «Нет»
```

После включения у Strawberry 18+ появляются «Предпросмотр» и «История», а в левом
меню — пункт плагина. Пока выключен, в настройках виден только переключатель.

Вложенных разделов в настройках Лампы нет, поэтому пункты плоские: каждый плагин
регистрирует свой компонент (`kinopoisk_settings`, `tv_settings`, `sisi_settings`,
`tvonline_settings`) через `Lampa.SettingsApi.addComponent`.

## Как это устроено

```
lampa-plagin.js            ← установщик: это и добавляется в Лампу
plugins/lgbt.js            ← флаг выключения раздела
plugins/kinopoisk.js       ← Кинопоиск
plugins/sisi.js            ← Strawberry 18+
plugins/tv.js              ← Телевидение (IPTV)
plugins/tvonline.js        ← ТВ онлайн (20 каналов)
```

Установщик берёт папку, из которой загружен сам, и по очереди подключает все
перечисленные файлы с меткой версии в адресе (сброс кеша). Если какой-то файл
недоступен — в консоли Лампы будет ошибка, остальные плагины загрузятся.
Повторное добавление установщика не создаёт дублей.

Поэтому плагины обновляются независимо: правите `src/…`, запускаете сборку,
и все клиенты подтягивают новую версию по метке версии.

В установщике есть проверка `window.Lampa` и текст с `Lampa.` — встроенная проверка
расширений Лампы считает файл плагином только если находит в нём эту подстроку,
иначе показывает ошибку 500 «не плагин».

## Плагины

### 1. Кинопоиск — «Буду смотреть»

Список из папки «Буду смотреть» на Кинопоиске прямо в Лампе.

Отличия от [and7ey/lampa](https://github.com/and7ey/lampa):

- OAuth-токен **не** отправляется в чужой Google Apps Script: запросы идут через
  собственный Cloudflare Worker, токен в теле POST, в URL не попадает и не логируется;
- адрес прокси и ключ задаются в настройках Лампы (Настройки → Кинопоиск → «Свой прокси»);
- авторизация через Яндекс: QR-код или код на `ya.ru/device`; после подтверждения токен
  подхватывается автоматически (опрос раз в 5 секунд, без нажатия «Готово»);
- грузится весь список, а не первые 50 (страницы по 20, потолок 1000);
- исправлены падение настроек, `undefined` в пустых полях и невнятные ошибки.

Код Worker и инструкция: [`proxy/cloudflare-worker/`](proxy/cloudflare-worker/README.md).

### 2. Strawberry 18+ (sisi, si.skaz.tv)

Контент-плагин с сервера `si.skaz.tv`, скопирован без изменений. По умолчанию
**выключен**: в настройках виден только переключатель «Включить», пункта в левом
меню и источника в поиске нет. После включения появляются настройки плагина
(предпросмотр, история) и кнопка в левом меню.

> ⚠️ Работает по **HTTP** (у `si.skaz.tv` нет TLS) и содержит канал удалённого
> управления: подключается по WebSocket к адресу из ответа сервера и выполняет
> команды через `eval`. На сервер уходят `account_email` из Лампы, `unic_id`,
> `box_mac`, `profile_id`.

Реклама перед видео (`bid.ctv.house`) отключена на уровне Private DNS телевизора,
к плагинам отношения не имеет.

### 3. LGBT — выключение раздела

Крошечный плагин-флаг (111 байт), копия `cubnotrip.top/plugin/lgbt`
(оригинальный адрес `cub.rip/plugin/lgbt` больше не существует — домен не резолвится):

```js
window.lampa_settings.disable_features.lgbt = true;
```

Ничего не регистрирует, никуда не ходит, `eval` и DOM не трогает — просто выставляет
флаг, по которому Лампа скрывает соответствующий раздел. Загружается первым, чтобы
флаг успел до построения меню.

### 4. Телевидение (IPTV)

Свой список каналов в Лампе: встроенный плейлист **M3U** и программа передач **XMLTV**.
Внешний вид — как в ТВ-разделе: слева категории и группы с количеством каналов,
справа список каналов. По умолчанию включён **список**: у каждого канала видно
«Сейчас» с временем и прогрессом, а под ним «Далее». Переключатель «Плитка»
возвращает сетку карточек с логотипами.

- **Плейлист встроен**: при открытии раздела сразу загружается
  `examples/federal20.m3u` — 20 федеральных каналов (и добавленные вручную
  каналы, если есть). Ссылка на плейлист в настройках не запрашивается.
  Каналы провайдера работают только в его сети и/или с токеном; с текущей сети
  они недоступны.
- **Программа передач** — из `x-tvg-url` плейлиста или из поля `Программа (XMLTV)`.
- **Список и плитка**: «Список» — строки с текущей и следующей передачей;
  «Плитка» — карточки с логотипами.
- **Категории**: «Все каналы», «Избранное», «Поиск» и группы из `group-title`.
  Счётчики пересчитываются автоматически.
- **Поиск** по названию канала и группы — по лупе в заголовке или пункту «Поиск».
- **Избранное** — долгое нажатие OK на строке или карточке. Хранится в `tv_favorites`,
  переживает перезапуск Лампы.
- **Плеер** — встроенный `Lampa.Player.iptv`: переключение каналов PG+/PG−,
  цифровой ввод номера, панель с текущей и следующими передачами.
- **Кэш** плейлиста и программы — 15 минут в памяти; кнопка «Обновить данные»
  в настройках сбрасывает его вручную.
- **CORS**: если сервер не отдаёт `m3u`/`xml` браузеру, укажите прокси.
  В поле можно вставить адрес с `{url}` (он заменится на закодированную ссылку)
  или просто префикс, к которому ссылка добавляется в конце.

Ограничения: один встроенный плейлист, без архива/catch-up и без разбора XMLTV
с префиксами пространств имён (`<tv:programme>`). Логотипы грузятся напрямую
с сервера провайдера; при ошибке показывается аббревиатура канала.

Готовый плейлист: [`examples/federal20.m3u`](examples/federal20.m3u) —
20 федеральных каналов (может быть дополнен каналами провайдера).
Программа передач: [`examples/federal20.xml`](examples/federal20.xml).
Обновление программы — `node scripts/update-epg.mjs`.

### 5. ТВ онлайн — 20 федеральных каналов

Отдельный плагин по странице
[Мегион-Линк «IPTV 20 федеральных каналов»](https://www.megion.biz/clients/iptv-20-federalnykh-kanalov-.php).
Открывается отдельным пунктом «ТВ онлайн» и **не связан** с плагином «Телевидение».

- 20 каналов: Первый, Россия 1, Россия 24, Россия К, Пятый, НТВ, Матч ТВ,
  Карусель, ОТР, ТВ Центр, РЕН ТВ, Спас, СТС, Домашний, ТВ-3, Пятница,
  Звезда, Мир, ТНТ, Муз-ТВ.
- Для каналов, где вещатель отдаёт прямой поток, используется он:
  1ТВ (DASH), ВГТРК/Smotrim, Матч ТВ, Звезда, ТНТ и Пятница (Rutube), Мир.
- СТС, РЕН ТВ, Пятый и Муз-ТВ идут с официального плеера MediaVitrina.
  У СТС и РЕН ТВ есть региональные версии (МСК+0/+2/+4/+7): плагин выбирает
  версию по часовому поясу устройства, поэтому трансляция совпадает с сайтом
  вещателя, а не идёт в другом сдвиге. Часовой пояс можно задать вручную
  в настройках.
- Резервный источник `31.148.5.241` — это хабаровский провайдер (МСК+7).
  Он остаётся только на случай, если официальная ссылка недоступна; для
  каналов на этом источнике программа передач сдвигается на +7, чтобы
  «Сейчас/Далее» совпадали с потоком.
- **Режим потоков** в настройках:
  - «Совместимые» (по умолчанию) — CORS-совместимые ссылки, работают в браузере;
    качество зависит от канала (720–1080p там, где вещатель отдаёт HD);
  - «Официальные HD» — те же ссылки вещателей; часть из них без CORS,
    поэтому нужен внешний плеер.
- Программа передач «Сейчас/Далее» — из `examples/federal20.xml`; для
  региональных версий время сдвигается вместе с каналом.
- Настройки: «Включить», «Потоки» и «Часовой пояс каналов». Ссылка на плейлист
  не запрашивается.

Официальные ссылки MediaVitrina содержат токен со сроком около 7 дней.
Их обновляет `node scripts/update-streams.mjs`; в GitHub Actions это делает
workflow `update-streams` раз в сутки и коммитит
[`examples/tvonline-streams.json`](examples/tvonline-streams.json).

Ограничения: часть официальных страниц использует DRM (Widevine), поэтому
их прямой поток не извлекается. Некоторые HTTPS-потоки не отдают CORS — в браузере
может понадобиться внешний плеер.

## Сборка

```
src/kinopoisk.js  ─┐
src/sisi.js       ─┼─ node build.mjs ─> plugins/*.js + lampa-plagin.js (установщик)
src/tv.js         ─┤
src/tvonline.js   ─┘
```

Правьте `src/`, затем `node build.mjs`, затем коммит.

Список плагинов задан массивом `plugins` в `build.mjs`: чтобы добавить следующий,
достаточно дописать туда элемент с путями `src` и `out` — установщик обновится сам.

## Состав репозитория

```
lampa-plagin.js              установщик (добавляется в Лампу)
plugins/lgbt.js              флаг disable_features.lgbt
plugins/kinopoisk.js         собранный плагин Кинопоиска
plugins/sisi.js              собранный плагин sisi
plugins/tv.js                собранный плагин телевидения
plugins/tvonline.js          собранный плагин «ТВ онлайн»
src/lgbt.js                  исходник флага
src/kinopoisk.js             исходник Кинопоиска
src/sisi.js                  исходник sisi
src/tv.js                    исходник телевидения
src/tvonline.js              исходник «ТВ онлайн»
build.mjs                    сборка
scripts/update-epg.mjs       обновление federal20.xml
scripts/update-streams.mjs   обновление официальных ссылок «ТВ онлайн»
.github/workflows/update-epg.yml      ежедневное обновление EPG
.github/workflows/update-streams.yml  ежедневное обновление ссылок
examples/federal20.m3u       встроенный плейлист 20 федеральных каналов
examples/federal20.xml       программа передач к нему
examples/tvonline-streams.json  официальные HLS-ссылки по часовым поясам
proxy/cloudflare-worker/     CORS-прокси для Кинопоиска (Cloudflare Worker)
```
