# lampa-plagin

Плагин «Strawberry» (sisi / si.skaz.tv) для приложения [Лампа](https://cub.red/lampa).

Код плагина скопирован с `http://si.skaz.tv/sisi.js` без изменений.

## Установка

```
https://gribanovden2024.github.io/lampa-plagin/sisi.js
```

Лампа → Настройки → Расширения → «Добавить плагин» → вставить адрес.

## Важно про безопасность

Плагин работает по **HTTP** (у `si.skaz.tv` нет TLS) и содержит канал удалённого
управления: подключается по WebSocket к адресу, который присылает сервер, и
выполняет команды через `eval`. На сервер уходят `account_email` из Лампы,
`unic_id`, `box_mac`, `profile_id`.

Следствия:

- любой в сети между телевизором и `si.skaz.tv` (провайдер, сосед по Wi-Fi)
  может подменить ответ и выполнить свой код внутри Лампы;
- `eval`-канал даёт сайту полный доступ к данным Лампы, включая токены.

Если это важно — канал RCH можно вырезать (плагин продолжит работать) или
поставить просмотр через VPN.
