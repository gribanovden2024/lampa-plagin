# Плейлисты

- [`playlist.m3u`](playlist.m3u) — **встроенный в плагин**: 20 федеральных каналов
  + 131 канал провайдера «Базовый». Именно этот файл плагин открывает сразу.
- [`federal20.m3u`](federal20.m3u) — только 20 федеральных каналов (базовый список).
- [`federal20.xml`](federal20.xml) — программа передач для федеральных каналов.

Программа передач: 20 каналов, около 4000 передач на неделю. Проверено `ffprobe`
25.11.2026. Потоки публичные, права принадлежат вещателям; адреса могут перестать
работать в любой момент.

Плейлист содержит `x-tvg-url` на этот XML, поэтому плагин подхватит программу
автоматически. В списке каналов видно «Сейчас» с прогрессом и «Далее».

> Каналы провайдера в `playlist.m3u` — это ссылки портала `tv.ot.net.ru`.
> Они работают только в сети провайдера и/или с его токеном; с текущей сети
> портал перенаправляет на недоступный `151.0.1.101:8801`.

## Обновление программы

```bash
node scripts/update-epg.mjs
```

Скрипт скачивает `https://epg.iptvx.one/epg.xml.gz`, оставляет 20 нужных каналов
и окно «12 часов назад … 7 дней вперёд», затем перезаписывает `federal20.xml`.
Запускать раз в 1–2 дня (можно повесить на cron или GitHub Actions).
В репозитории уже есть `.github/workflows/update-epg.yml` — обновляет файл
раз в сутки и коммитит изменения.

## Как использовать

1. Сохранить `federal20.m3u` на свой сервер или в GitHub Pages.
2. В Лампе: **Настройки → Телевидение → Плейлист (M3U)** — указать ссылку.
3. EPG в этом плейлисте нет, поэтому в карточках будет название канала.

Если встроенный плеер не открывает поток из-за CORS:

- включить внешний плеер (VLC/MX Player) в настройках Лампы;
- либо заменить ссылку на SD-вариант с `31.148.5.241` (у него
  `Access-Control-Allow-Origin: *`).

CORS-совместимый вариант на 20 каналов: все ссылки с `31.148.5.241`
(1–11 и 13–20) плюс `kanal_12` (Спас). Но это будет без Ю и почти всё в 576p.

## Проверка

```bash
ffprobe -v error -select_streams v:0 \
  -show_entries stream=width,height,codec_name -of csv=p=0 \
  "http://31.148.5.241/kanal_1/index.m3u8"
```
